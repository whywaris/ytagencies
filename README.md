# YT Agencies

Directory for finding a YouTube agency by service, industry and location: https://ytagencies.com

Read `CLAUDE.md` first, then `docs/DESIGN.md`, `docs/SEO.md` and `SECURITY.md`. Launch steps: `docs/LAUNCH.md`.

```bash
pnpm install
cp .env.example .env.local   # fill in values
pnpm dev
```

Database: run `supabase/schema.sql`, then `supabase/seed.sql`, in the Supabase SQL editor.
